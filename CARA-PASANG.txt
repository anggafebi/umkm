PATCH STATUS PESANAN ADITECH

Patch ini dibuat berdasarkan file resources/views/admin/orders/index.blade.php
yang kamu unggah.

1. Ekstrak ZIP.
2. Salin folder resources ke D:\laragon\www\umkm\
   sehingga file tujuan menjadi:
   D:\laragon\www\umkm\resources\views\admin\orders\index.blade.php
3. Timpa file jika Windows meminta konfirmasi.
4. Jalankan dari terminal pada folder proyek:

   php artisan view:clear
   php artisan optimize:clear

5. Buka /admin/orders lalu tekan Ctrl + F5.

Pemetaan badge mengikuti kelas status yang sudah dipakai halaman konsultasi:
- Baru: kuning
- Ditinjau / Dalam Pengerjaan: kelas contacted
- Menunggu Persetujuan: ungu
- Disetujui: hijau
- Selesai: abu-abu
- Dibatalkan: merah

Hanya satu file Blade yang diubah. Tidak ada perubahan database, route,
CSS global, konfigurasi, atau folder .git.
