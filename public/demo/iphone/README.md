# FORME — iPhone Store Demo

Demo katalog toko iPhone dengan HTML, CSS, dan JavaScript murni.

## Isi folder
- `index.html` — struktur halaman.
- `style.css` — tampilan minimalis dan responsif.
- `script.js` — pencarian, filter, detail produk, keranjang, dan simulasi checkout.
- `assets/products/` — foto produk berformat JPG.
- `.htaccess` dan `index.php` — entry point yang dipertahankan untuk lingkungan demo Laragon/Apache.

## Cara memasang
1. Cadangkan folder lama `umkm/public/demo/iphone`.
2. Hapus atau pindahkan folder lama setelah membuat cadangan.
3. Ekstrak folder `iphone` dari ZIP ini ke `umkm/public/demo/`.
4. Buka ulang `/demo/iphone/` dan tekan `Ctrl + F5`.

## Catatan
- Harga, nama varian, dan spesifikasi merupakan data contoh untuk demo; verifikasi sebelum digunakan untuk penjualan nyata.
- Foto JPG di paket ini adalah visual produk bergaya fotorealistis yang dibuat untuk demo, bukan foto resmi yang dijamin merepresentasikan varian Apple tertentu.
- Keranjang dan checkout hanya simulasi frontend; tidak ada pembayaran atau pesanan yang dikirim ke server.
