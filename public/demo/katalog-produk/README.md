# Website Katalog Produk — Demo

Website katalog sederhana menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak folder `website-katalog-demo`.
2. Buka `index.html` di browser, atau sajikan melalui server lokal proyek.
3. Produk, harga, kategori, deskripsi, dan nama file gambar dapat diedit pada array `products` di `script.js`.

## Fitur
- Pencarian produk dan filter kategori.
- Kartu produk dengan foto, harga, kategori, dan label.
- Modal detail produk.
- Formulir pertanyaan produk dengan pratinjau pesan dan tombol salin.
- Layout responsif untuk desktop dan ponsel.
- Semua foto produk disimpan lokal di `assets/products/`.

Formulir hanya simulasi frontend dan tidak mengirim data ke server. Ganti konten contoh dan tambahkan integrasi kontak/backend sesuai kebutuhan sebelum digunakan secara nyata.
