# RITMO — Retro Shoe Store Demo

Demo toko sepatu online bergaya retro menggunakan HTML, CSS, dan JavaScript murni.

## Isi folder
- `index.html` — struktur halaman.
- `style.css` — desain retro-modern dan responsif.
- `script.js` — pencarian, filter, detail produk, keranjang, dan checkout demo.
- `assets/products/` — foto produk sepatu berformat JPG.
- `.htaccess`, `index.php`, dan `robots.txt` — helper entry point yang dipertahankan untuk lingkungan demo.

## Cara memasang
1. Cadangkan folder lama `umkm/public/demo/sepatu`.
2. Ekstrak folder `sepatu` dari ZIP ini ke `umkm/public/demo/`.
3. Timpa file lama jika diminta.
4. Buka ulang `/demo/sepatu/` lalu tekan `Ctrl + F5`.

## Catatan
- Data produk, harga, dan transaksi merupakan simulasi untuk demo.
- Keranjang dan checkout tidak terhubung ke backend atau pembayaran nyata.
